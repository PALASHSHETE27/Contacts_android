# 📱 TheContacts

TheContacts is an Android contact management application developed using Java and SQLite. The app allows users to store, search, update, and delete contacts, along with adding profile images for each contact.

## Features

* Add new contacts
* Update existing contacts
* Delete contacts
* Search contacts in real time
* Store profile images
* Local data storage using SQLite
* User-friendly interface

## Tech Stack

* Java
* Android Studio
* SQLite Database
* RecyclerView
* View Binding
* ConstraintLayout

## How to Run

1. Clone the repository.
2. Open the project in Android Studio.
3. Build and run the application on an emulator or Android device.
